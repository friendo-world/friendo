Your site is a folder.

friendo is a local-first website builder. Build the folder on your machine, publish it anywhere. Three commands and you have a running site:

curl -fsSL https://raw.githubusercontent.com/friendo-world/friendo/main/scripts/install.sh | sh
friendo init my-site && cd my-site
friendo serve
