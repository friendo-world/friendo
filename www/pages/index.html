A local-first website builder

Your site is a folder.

Build it on your machine. Publish it with one command. Take it anywhere. No lock-in, and no magic you can't see.

explore the docs
friendo.toml

One small config file.

The site's name, which content collections it has, and where friendo deploy sends it. About ten lines. You will rarely open it.

read about friendo.toml
layouts/

The frame around every page.

A layout is the HTML that wraps a page: the head, the header, the footer. Pages extend a layout and fill in the middle.

read about layouts
layouts/base.html

The one layout most sites need.

Your stylesheet, your nav, your footer, and a {{ "{% block content %}" }} where each page goes. Add more layouts when you want a different frame.

read about layouts and blocks
pages/

Each file is a URL.

pages/about.html is /about. Pages are plain HTML with a little template logic: {{ "{{ post.title }}" }} is a post's title. That's most of it.

read about pages and URLs
pages/index.html

The front door.

Your home page, served at /. Write it like any HTML file, and loop over a collection to list your posts.

read about your first site
pages/blog/

A folder is a path.

Everything in pages/blog/ lives under /blog. Nest folders as deep as you like; the URLs follow.

read about pages and URLs
pages/blog/[slug].html

One file, a page for every post.

The square brackets mean: render this once per record in the blog collection, at /blog/its-slug. Add a post and its page just exists.

read about collections
content/

Posts as markdown files.

Drop hello.md in content/blog/ and it's a post. Or write in the admin. Either way it lands in the same little database.

read about authoring in files
data/

The site's memory.

Created the first time you run friendo serve. Holds the database. Not something you edit by hand, but yours to back up or move.

read about portability
data/friendo.db

Everything, in one SQLite file.

Posts, comments, members, reactions, poll votes. One file you can copy, check into git, or open with any SQLite tool. No server to lose it in.

read about portability
Make your first site 
curl -fsSL https://raw.githubusercontent.com/friendo-world/friendo/main/scripts/install.sh | sh
friendo init my-site
cd my-site && friendo serve

, then run them in your terminal.
