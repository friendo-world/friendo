Your site is a folder.

Build it on your machine. Publish it with one command. Take it anywhere — friendo is a local-first website builder with no lock-in and no magic you can't see.

curl -fsSL https://raw.githubusercontent.com/friendo-world/friendo/main/scripts/install.sh | sh
friendo init my-site
cd my-site && friendo serve

Make your first site → Already have one? Sign in.

A folder you own

Templates, pages, assets and a SQLite database, sitting in a directory. Check it into git. Export it to plain HTML. It outlives any tool — including this one.

Community, one tag at a time

Comments, reactions, polls, chat, maps and forms are each a single tag: <friendo-comments>. No JavaScript to write.

Publish in one command

friendo deploy puts your folder at my-site.friendo.world. Sign in with a code sent to your email — there's no password to make up.

Or host it yourself

The same binary serves one site on a server you own, or a whole network of them by subdomain. friendo.world is just the reference network.

How it feels

1

Write pages as plain HTML with a little template logic. {{ "{{ post.title }}" }} is a post's title. That's most of it.

2

Write content in the admin, or as markdown files in content/. Either way it lands in the same little database.

3

Publish with friendo deploy. Open the admin from your account page, invite people, connect your own domain.
